# docs/network-diagram/

Per-region network diagrams — one file per region (e.g. `scotland.md`, `danmark.md`), split out of
a single 51-diagram file because GitHub's mermaid renderer got unreliable with that many diagrams
on one page.

The Visual Standard, emoji legend, and links to every region file live in
[../network-diagram.md](../network-diagram.md) — start there, not here.

See [../INDEX.md](../INDEX.md) for the full documentation index.
