## Visual Standard

Every per-site diagram in this file is split into two labelled boxes:

- **Old Network (legacy)** — this file's original content, sourced by hand over time. Kept as-is data-wise; not regenerated.
- **New Network (current)** — generated from `benarbejde/sites.csv` + `benarbejde/devices.csv` + `benarbejde/address_policy.json`, the actual single source of truth for the estate. Regenerated by `benarbejde/generate_network_diagrams.py` and checked for drift by the test harness (`ansible/at_have_ryggen_fri/`, check 14) — if you edit a New Network box by hand, the next harness run will flag it as stale.

**One uniform shape, emoji does the "what is this" job.** Every node in every box (both Old and
New Network) is a plain rect — `["<emoji> label"]` — no per-class shape geometry. This replaced an
earlier 5-shape system (hexagon/cylinder/circle/stadium/flag) on Robert's call, 2026-07-13: across
a 50+ node diagram, five different shapes with their own drop-shadows read as visual noise rather
than signal — "more shapes than the Ministry of Sound." One shape keeps every diagram calmer to
scan; the emoji still tells you what a node is at a glance. Full symbol table, reasoning, and the
handful of "no real Unicode character for that" substitutions: **[`docs/emojis/README.md`](emojis/README.md)**.

**Single-line labels.** Node text is joined with ` · `, not `<br/>` — one line per node instead of
two or three. Shorter boxes, same information.

**Colour = old vs new**, applied once per box (not per site, not per node — 53 sites of per-site colour would be unreadable, and colourblind-unfriendly with it):

| Box | Fill | Notes |
|---|---|---|
| Old Network (legacy) | `#56B4E9` (sky blue) | Okabe–Ito colourblind-safe palette |
| New Network (current) | `#E69F00` (orange) | Okabe–Ito colourblind-safe palette |
| Issue flagged (`warn`) | `#D55E00` (vermillion) on `#000000` text | Distinct from the above under all common colour-vision deficiencies; replaces this file's former per-diagram ad-hoc `warn`/`net` colours, several of which were red/green pairs — a real colourblind hazard found during the 2026-07-13 audit, not a hypothetical one. |

**Unicode symbols, not icon fonts.** A literal Unicode character prefixed to the node label — confirmed via a live kroki.io round-trip 2026-07-13 to render reliably with no external dependency. FontAwesome-class icon syntax (`fa:fa-x`) and Mermaid's newer `@{ icon: }` syntax were tested the same way and do **not** reliably render through this pipeline (unstyled CSS class with no attached webfont, or a silent fallback to a generic default shape) — do not use either. Real Cisco stencils, an AT&T logo, an Atari logo and a jukebox glyph are not options either (trademarked, or simply don't exist as Unicode — see `docs/emojis/README.md` for what stood in for each). Any device not yet assigned a symbol carries a literal `❓` placeholder pending sign-off — see `ansible/at_have_ryggen_fri/README.md`'s Backlog section.
