# Non-IT company equipment

Reference photos for real company assets that have no IT/network footprint — no hostname, no IP,
no `devices.csv` row, since that file is an IT/network device inventory, not a general company
asset register. Distinct from the rest of `vehicles/`, whose photos each correspond to a real
`devices.csv` row (see that directory's own `README.md`).

More categories (boardroom equipment, etc.) to be added here later.

## Vehicles

The filenames follow the same `EXA<TYPE><SITE><NNN>` shape as the rest of `vehicles/` for
consistency, even though there's no corresponding `devices.csv` row to match against — treat
these as location labels, not device identifiers.
