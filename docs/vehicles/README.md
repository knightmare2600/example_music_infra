# docs/vehicles/

Reference photos for the curveball/novelty devices in `benarbejde/devices.csv` (FAL's tour buses,
cars, jet, trucks, etc. — see `docs/emojis/README.md`'s curveball table for the full device list
and their diagram symbols). Not currently linked from any doc — kept here for reference.

Filenames follow `EXA<TYPE><SITE><NNN>.png`, matching the device's own `devices.csv` row exactly
(e.g. `EXATRKFAL001.png` = FAL's `TRK1`). A trailing letter (`EXACARFAL001b.png`) means an
alternate/second photo of that same device.

A handful of photos in this directory (`EXAVANFAX001.png`, `EXACARBON001.png`,
`EXACARBRK001.png`, `EXACARMIA001.png`, `EXACARODE001.png`) do **not** correspond to any
`devices.csv` row — they're real company vehicles with no IT/network footprint, so they were
never given one. See [non-it-equipment.md](non-it-equipment.md).
